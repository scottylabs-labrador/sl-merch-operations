Access codes

Each person signs in at /login with their own code instead of a shared passcode. Volunteer codes (VOL-…) reach the pickup page; admin codes (ADM-…) reach this whole admin area. Generate a batch, hand one to each person, and revoke any code the instant it should stop working — revoking ends that person's current session immediately and no one else is affected. {% if shared_enabled %}The shared VOLUNTEER_PASSCODE / ADMIN_PASSCODE still work as fallbacks; clear them in the environment once everyone is on a code.{% else %}The shared volunteer passcode is disabled, so codes are the only way in for volunteers.{% endif %}
